# Inspect Mode

Inspect the requested repository scope without changing files, running shell
commands, or using the network. Build a bounded evidence map from the exposed
read, grep, find, and list tools. Distinguish observed facts from inferences,
cite repository-relative paths, identify trust and capability boundaries, and
return unresolved questions instead of guessing.

Completion requires a structured inspection result with: scope, relevant
entry points, data/control flow, concrete risks, and the evidence supporting
each claim. This M1 resource defines the contract only; runtime activation is
unavailable until the Mode Registry is delivered in M3.
