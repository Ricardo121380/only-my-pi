# Only-My-Pi 界面原型

默认的 `index.html` 保留五个方向的模拟比较。选定的设计已成为 WebUI，
`minimal.html` 实时入口通过 `src/native/` 接入原生 Pi/Host；在仓库根目录
运行 `npm run dev:web:b2:demo`。依赖安装、真实工具、审批和历史恢复的步骤见
[WebUI 开发说明](../docs/minimal-webui.md#webui-frontend-with-the-native-pi-host)。
实时入口使用真实账号、工具、只读子代理和输入回执；原型中的模拟写入子代理、
受管克隆、检查结果和差异应用不代表已经接入产品。

五个可交互的方向，共用同一个模拟会话（给侧栏加“会话归档”），便于横向比较。顶部切换条或 `Alt+1…5` 切换，地址栏 `#a`、`#b`、`#b2`、`#c`、`#d` 可直接定位。

| 方向 | 参考 | 布局 | 标志性元素 |
| --- | --- | --- | --- |
| A 工作台 | Codex | 三栏可拖拽：项目会话、对话、审查面板（改动、验证、预算） | 顶部“权限轨道”：只读检查 → 规划 → 编程 |
| B 静室 | Claude 桌面版 | 可收起侧栏，居中衬线阅读列，计划与改动在右侧页展开 | 带页边批注的计划文档（风险、验证写在页边） |
| B2 静室·编码 | B 的风格 | 可收起侧栏（项目切换与归档分组）、阅读列、可拖拽的常驻工作区（计划、改动、文件、终端）、底部状态栏 | 审批停靠在输入框上方；正文中的文件名可点开；⌘K 命令面板，@ 引用文件，/ 命令 |
| C 原生 | Pi Desktop | 深色高密度：会话项目树、对话、文件改动终端工作区 | 主 Agent 与子代理的连线树，运行中带光束 |
| D 指挥台 | DeepSeek Harness | 图标导航、预算区、任务看板、右侧任务详情 | 子代理费用半圆仪表与按参与者累计的 Token 曲线 |

B2 的设计规范见 [DESIGN.md](DESIGN.md)，切换条里的「规范」是同一份规范的在线样张（由实际组件渲染，可切换日夜）。

所有方向都可以：批准、要求修改计划、保持只读、撤销授权；停止运行；切换账号、模型与思考强度。授权状态在各方向之间共享。

## B2 的完整任务旅程

B2 在批准后会按 OMP 直接运行时的阶段推进（`src/prototypes/b2/run.ts`），全程约 15 秒：

1. 两个只读侦察者梳理项目，写入者在受管克隆中逐个编辑文件。
2. 克隆里运行检查，生成补丁 v1，全新审查者审查并在 `contracts.mjs` 第 49 行留下 1 条建议。
3. 在“改动”里点行号写意见、标记文件已查看；“请求修改”让写入者处理全部意见，生成补丁 v2 并重新审查。
4. “应用到工作树”需要二次确认；应用后在真实工作树重新运行三条验证，状态栏未提交数从 3 变为 7，不暂存、不提交。

运行中可以“补充”（下一个可接收位置生效）或“排队”（当前任务结束后手动发送），也可以停止或收回授权，未完成的子代理和命令会标为已取消。状态栏有“重新演示”和夜间模式切换。

## B2 的首次配置与新会话

第一次打开 B2 会进入首次配置（之后可在 ⌘K 里选“重新运行首次配置”）：

1. **模型账号**：选服务商（DeepSeek、Anthropic、OpenAI 兼容、本机模型），用 API Key 或浏览器登录，测试连接后选默认模型和思考强度；也可以只读引用终端里的 Pi 默认账号。密钥为空、被拒绝（401）都有明确的修复提示。原型只模拟连接，不发送任何请求。
2. **运行环境**：逐项检查 Node、Pi、Git、命令沙箱、权限模式、ripgrep 和本机 Host，标出 Pi 1.5.0 的版本差距，缺失依赖给出可复制的安装命令。
3. **第一个项目**：识别 Git 分支、未提交改动、AGENTS.md 和验证命令；非 Git 目录会说明影响和处理办法。

新会话首页（⌘N）：选择“检查与提问”或“规划改动”；上次的模型只高亮，必须点“使用”或另选才能发送；从项目现状生成的起点、一键引用未提交文件、继续旧会话（不恢复旧授权）。右侧工作区在新会话里是项目概览：工作树、最近提交、项目规则、验证命令和本次会话加载的内容。

## B2 的设置与多账号

侧栏底部“设置”（⌘,）。有账号需要处理时，入口和分类上会显示数量。

- **账号与模型**：按服务商分组的产品账号，加上只读引用的 CLI 默认账号。每个账号有真实状态：可用、密钥被拒绝（更换密钥）、登录已过期（浏览器重新登录）。展开后可以设默认模型、测试连接、重命名、查看绑定的会话和本月用量。删除在页面内确认：有会话正在用时不能删；有历史会话绑定时会说明它们之后只能查看。分类与生图单独绑定账号和模型，绑定的账号失效时任务会停下，不会改用其他账号。
- **工具与技能**：产品默认与项目覆盖两层，项目里显示“继承默认”或“已覆盖”，可以恢复继承；必需组件锁定。
- **MCP 连接**、**子代理预算**、**外观**（主题、阅读字号）、**运行环境**（版本、已配对的浏览器）。

新会话和输入框里的账号选择器读取同一份账号状态：失效账号不能选，只提供“去设置处理”。
窗口宽度低于 720px 时设置分类改为顶部标签，低于 900px 时右侧工作区默认收起。

## 运行

```bash
npm install
npm run dev
```

## 技术栈

React 19、Vite、Tailwind CSS v4、shadcn/ui（new-york，Radix UI）、Lucide React、Motion、react-resizable-panels v4、dnd-kit、Zustand、TanStack Query、Recharts。Magic UI 的 Border Beam、Animated Shiny Text、Number Ticker 与 Aceternity UI 的 Text Generate Effect 以源码形式放在 `src/components/magic`。

默认比较入口的数据来自 `src/data/mock.ts`，`src/data/queries.ts` 用 TanStack Query
模拟本机 Host 的延迟。`src/native/` 实时入口使用 Host HTTP/WS 和 Pi 历史，
不导入模拟运行器或原型状态。
