# Glacier WebUI 接入记录

日期：2026-09-21。结论：Glacier 视觉方案已适配到现有 React WebUI 源码，并通过前端构建、类型检查、9 项组件测试及确定性浏览器检查；这不是完整原型功能交付，也不是已安装 OMP 的升级记录。

## 第三轮：直接迁移原稿（当前实现）

前两轮重新编写样式造成了持续偏差。本轮不再重绘视觉系统：`main.tsx` 改为加载 `prototype.css` 与仅用于真实 Host 内容的 `host-ui.css`，旧 `style.css`、`glacier.css` 均不再加载，但保留文件。

- `scripts/sync-glacier-assets.mjs` 从原始 HTML 的 head 中机械提取两段完整样式和 57 个 SVG 符号；不执行原型 JavaScript。`node scripts/sync-glacier-assets.mjs --check` 可验证生成文件与原稿完全一致。
- 导航、主页、标题栏、输入托盘、消息、检查区、底部输出和外观弹窗按原稿 DOM/class 结构迁移为 React；真实数据、发送、取消及文件 API 沿用 Host。
- 原稿中的附件、推理强度、插件等未接入入口保留位置并禁用；不伪造费用、模型能力、分支或运行结果。
- 补回搜索快捷键、底部面板键盘与拖动调高、窄屏抽屉焦点约束、Escape 关闭及焦点恢复。
- 同尺寸 1440×960 测量：左栏、主标题栏、右侧标题栏及品牌标识的几何尺寸与字体一致。输入托盘仍有约 2px 高度差；项目名、模型名与上下文内容不同，未宣称全页面逐像素一致。

本轮构建、TypeScript 检查、9/9 组件测试、资源一致性检查及 diff 检查通过。Ego Lite 使用确定性 Host 夹具检查模型选择、建议填入、流式取消、输出面板调高、移动抽屉与弹窗；检查了 1440、761、390px 宽度，没有调用真实模型。390px 稳定布局实测画布宽 390px、页面无横向溢出。调整视口后需等待布局与动画稳定，不能把过渡帧当作验收截图。

## 第二轮：按原型重新校准布局

第一轮只移植材质与颜色，保留了旧版全宽顶栏和重复标题、裸文件列表，视觉结构与原稿存在明显偏差。第二轮以同尺寸 1440×960 的 HTML 截图重新校准：

- 品牌回归左侧全高导航；主标题、状态和面板控制回归内容栏顶部，右侧检查区从窗口顶部对齐。
- 桌面默认显示检查区；项目速览与文件列表使用原稿的卡片层次，内容仍来自真实 Host 数据。
- 输入托盘收紧，模型移到右侧，保留只读模式说明；消息增加角色标识、右对齐用户气泡和较克制的正文排版。
- 新增项目主页入口卡片，实际动作仅聚焦输入或打开项目检查，不自动发送模型请求。
- 761–1100px 打开检查区时暂时收起左侧树，避免正文被三栏挤窄；关闭检查区恢复导航。
- 修正深色透明侧栏的底层背景，避免出现第一轮的灰白透底。

再次通过 Web 构建、前端类型检查及 9 项组件测试。Ego Lite 检查了确定性任务完成、文件打开、Git diff 读取、手机输出面板 Escape/焦点恢复及系统减少动态效果（transition 为 0s）。检查尺寸为 1440×960、761×900、390×844。未调用真实模型。

第二轮实际截图：`refined-home.png`、`refined-session.png`、`refined-dark.png`、`refined-761.png`、`refined-mobile.png`；原稿同尺寸截图为 `reference-1440.png`，均位于上述本机 artifacts/glacier 目录。原型展示的模拟结果卡、插件列表、用量数据没有移植为虚假的产品能力；当前不是逐像素复刻。安装包仍未推广。

## 本次实现

- `webui/src/glacier.css`：冰川蓝浅色、石墨深色、玻璃输入区、项目导航、卡片及响应式布局；减少动态、透明度和高对比偏好降级。
- `App.tsx`：项目下嵌套任务与完整历史；顶部独立控制检查区和输出区。完整历史不受最近 15 个任务上限影响。
- `Composer.tsx`：项目上下文、模型选择、发送/取消及双行指标区域。未有真实数据的指标显示“—”，不使用原型模拟数值。
- `OutputDock.tsx`：只读工具结果，关闭不取消任务；手机使用原生模态面板，Escape 关闭后焦点回到触发按钮。
- `Appearance.tsx`、`Icon.tsx`：页面级外观设置和本地 SVG 图标。不新增依赖，不修改系统配置。
- 现有 Host/Pi RPC、安全边界、历史读取、取消逻辑和 Inspector API 保持不变。

设计实施采用 frontend-design 的视觉方向指导、frontend-ui-craft 的完整交互状态及 ui-ux-pro-max 的焦点规则；以用户原稿为准，不重新生成风格。
