# [G2-00-02] 闭合其余生成输入及工具分发条件

## Parent

规格：[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)。需求：US-009、US-010，并遵守 US-001–US-004 的共同约束。出口：G2-00 下 F02 的 native 材料子集；本工单通过不等于整体 F02/G2-00、Full 或 U2 通过。

## What to build

基于已保留的 368 项逐输入清单，为除 libexif 文档归档外仍缺生成证明的输入建立独立新候选，并完成宏/脚本的固定工具来源、当前操作条件和后续分发义务交接。维护者能核对候选生成物所用的源、规则、工具与必要原文；结果作为独立 supplement，既有材料不覆写。

## Acceptance criteria

- [ ] 剩余八项分别收口：libffi ChangeLog、libffi PDF、libffi/exif/webp/expat/archive 的五个 autoheader 模板，以及 Expat 平台配置输出；每项记录源/工具版本、具体输入、生成规则和输出绑定。已验证五模板的字节与适用范围匹配时复用原证据；libffi ChangeLog、libffi PDF 与 Expat 平台配置须取得固定输入并实际生成新结果，绑定具体 Git 范围/调用、TeX 工具输入及平台/编译探测/config.status。
- [ ] 既有 spec、stdint、stamp-vti 的三个静态内容对应继续保留，明确它们不等于历史运行/日期/编译探测证明；libexif 文档生成域由 [#20](https://github.com/Ricardo121380/only-my-pi/issues/20) 独立覆盖。
- [ ] 111 个完整宏/脚本沿现有十个材料家族逐项指向实际固定工具来源与完整声明，保留聚合宏内部的不同范围，不能把版本字段统一为本机工具或父包版本。HTTP 比较包不能单独充当可信供应；Debian patchset、GNU config 快照等缺口须绑定可信固定来源，或按已确认范围形成明确的新候选，保留旧比较材料与失败。
- [ ] 对 Autoconf、Libtool、Texinfo 的各类输出/分发例外及包自身 notice，记录实际拟分发场景、适用前提及当前/后续履行证据。当前复制生成所需条件必须满足；依赖实际应用构建、最终包和分发的条件分别绑定 G2-00-04/05，不要求先创建 #23 kit 才能验收本材料切片。文本已保留不等于条件已履行，任何当前必需条件不得挪后。
- [ ] 对无法证明原发行生成过程的条目保留历史 UNVERIFIED；若通过新的确定生成候选完成要求，绑定新输出身份，明确更换来源链，不冒充恢复历史。
- [ ] 新 supplement 的完整字节/执行位清单、摘要、离线复验和缺输入/未审核 overlay/漂移负例可核验。当前候选未知来源、实际生成或当前操作的必要条件尚未闭合时保持 PARTIAL/BLOCKED；后续阶段证据如实记待验。
- [ ] 不重新判定已绑定的 Windows/gettext/xmlwf 材料为缺失；保留原版权、完整例外文本、源包范围及各批失败记录。

- [ ] 对本工单中新生成的对象，在同一固定环境的两个独立目录实际生成，完整输出集合与字节一致；输入、工具、配置、环境和输出身份均有回执，不能仅复制旧结果或删除未知字段后比较。
- [ ] 逐项解释旧新差异，材料阶段可观察的内容、结构和接口兼容检查通过；依赖真实应用构建/Pi/资源运行的证明挂到 G2-00-04，未执行不记 PASS。
- [ ] 通过现有材料 CLI 的最高可行公开入口，完成双 Node 校验、实际禁网/同策略网络负例及受影响的缺输入、漂移、未审核 overlay、用途或别名拒绝；全部失败留证，Standards 与 Spec 分别记录。

## 新候选与阶段关闭边界

本次修订采用已确认的新可复现候选路线：优先保持现有组件版本，固定来源/工具/配置/环境并实际生成；允许新旧输出不同，逐项解释差异并验证本阶段可观察的内容、结构及接口兼容。新输出使用独立身份；保留旧候选、原完整材料、历史 UNVERIFIED 和失败记录，不裁剪源树/vendor/必要声明来消除缺口。组件版本、功能范围或接口合同若必须改变，先单列影响再确认。

本工单关闭须满足当前候选的所有材料完成条件及当前复制/生成必需条件。每项后续义务绑定对象身份、原文、拟用途、适用前提、所需证据与具体 Gate：新 kit 总核验归 #23，真实应用构建及其条件证据归 G2-00-04，最终包/默认发行/ledger/双 SBOM/notices 与分发履行归 G2-00-05，隔离 Full 与发行核对归 G2-00-06。属于当前动作的前提不可推迟；属于后续事件的证据保持待验并明确交接。材料切片通过不把整体许可 INCOMPLETE、实际分发或 Full 改为 PASS。

## Blocked by

无本批工单前置。复用既有 notice、generated-materials、Windows 和 locale 固定材料；与本批其他材料工单分别取证，输出隔离。
