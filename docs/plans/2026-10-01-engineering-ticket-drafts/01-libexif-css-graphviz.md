# [G2-00-02] 闭合 libexif 文档生成链的剩余材料

## Parent

规格：[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)。需求：US-006、US-007、US-010，并遵守 US-001–US-004 的共同约束。出口：G2-00 下 F02 的 native 材料子集；本工单通过不等于整体 F02/G2-00、Full 或 U2 通过。

## What to build

基于冻结的 libexif 源码与已有精确对应，为缺失生成链建立独立的新文档材料候选，覆盖 CSS、五图、其余文档/索引数据和必要声明。维护者能从实际取得的固定输入沿真实生成步骤复验新输出，并核对它与旧候选的差异；旧候选和已验收材料完整保留。

## Acceptance criteria

- [ ] 完整保留旧 CSS 及其精确对应；新文档候选首选沿用已绑定的 Doxygen 1.16.1 和 Graphviz 14.1.2；绑定 Doxygen 固定来源/版本、模板、实际有效配置与生成命令，CSS 全字节有实际生成证明。旧候选历史配置继续 UNVERIFIED，不阻止证据完整的新候选按自身身份验收。
- [ ] 五个图的职责与内容覆盖保持，新 Graphviz SVG 的工具来源/版本、实际 dot 输入、运行环境、生成步骤和输出声明分别绑定；不根据 SVG 的工具标记或父库许可推定图的许可。
- [ ] 对其余文档页、索引数据与 footer 实际生成并逐项绑定输入、配置、输出与必要声明；以原 106 文件范围建立完整的新旧对应，文件集合变化逐项说明；不能把 19 源码页的对应结果当整份归档重建。
- [ ] 已验收的六组件、九资产、原版权和失败报告保留，只有新增证明范围获得新结果；现有精确对应不重复改写。
- [ ] 新补充材料有完整文件清单、摘要、执行位及来源回执。固定本地输入可实际离线复验，漂移/缺输入时拒绝并保留失败证据；禁网结论由实际策略与负例证明。
- [ ] 对当前新候选逐项记录适用条件、当前履行与后续 Gate。当前复制/生成必需来源或条件仍 UNBOUND/UNVERIFIED 时不得关闭；旧候选未核历史与后续事件待验分列，不升级为整体 G2-00、Full 或完整法律结论。

- [ ] 对本工单中新生成的对象，在同一固定环境的两个独立目录实际生成，完整输出集合与字节一致；输入、工具、配置、环境和输出身份均有回执，不能仅复制旧结果或删除未知字段后比较。
- [ ] 逐项解释旧新差异，材料阶段可观察的内容、结构和接口兼容检查通过；依赖真实应用构建/Pi/资源运行的证明挂到 G2-00-04，未执行不记 PASS。
- [ ] 通过现有材料 CLI 的最高可行公开入口，完成双 Node 校验、实际禁网/同策略网络负例及受影响的缺输入、漂移、未审核 overlay、用途或别名拒绝；全部失败留证，Standards 与 Spec 分别记录。

## 新候选与阶段关闭边界

本次修订采用已确认的新可复现候选路线：优先保持现有组件版本，固定来源/工具/配置/环境并实际生成；允许新旧输出不同，逐项解释差异并验证本阶段可观察的内容、结构及接口兼容。新输出使用独立身份；保留旧候选、原完整材料、历史 UNVERIFIED 和失败记录，不裁剪源树/vendor/必要声明来消除缺口。组件版本、功能范围或接口合同若必须改变，先单列影响再确认。

本工单关闭须满足当前候选的所有材料完成条件及当前复制/生成必需条件。每项后续义务绑定对象身份、原文、拟用途、适用前提、所需证据与具体 Gate：新 kit 总核验归 #23，真实应用构建及其条件证据归 G2-00-04，最终包/默认发行/ledger/双 SBOM/notices 与分发履行归 G2-00-05，隔离 Full 与发行核对归 G2-00-06。属于当前动作的前提不可推迟；属于后续事件的证据保持待验并明确交接。材料切片通过不把整体许可 INCOMPLETE、实际分发或 Full 改为 PASS。
