# [G2-00-02] 闭合 GIR 供应与加工链及手册引文

## Parent

规格：[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)。需求：US-008，并遵守 US-001–US-004 的共同约束。出口：G2-00 下 F02 的 native 材料子集；本工单通过不等于整体 F02/G2-00、Full 或 U2 通过。

## What to build

针对旧 GIR 历史供应输入缺失，建立独立的新 GIR 材料候选：实际取得固定供应包或源码与未加工输入，记录确定加工步骤及内嵌文档/手册引文的原文材料。保留旧 53 文件/40 GIR 的完整覆盖范围、目标平台与原 kit，形成旧新差异和可离线复验的新来源链。

## Acceptance criteria

- [ ] 沿用现有 53 文件/40 GIR 的覆盖清单，逐项冻结本次实际取得的供应包或源码/构建来源、版本、未加工字节与摘要；Linux、Windows、macOS 输入分别留证，浮动标签和 VERSION 线索不能代替固定来源。旧历史包未取得仍如实记录。
- [ ] 从本次未加工输入到新 GIR 候选的完整加工链、工具版本、配置和手工修订有明确记录并实际离线执行；原始/派生字节分开绑定，不以从已加工 XML 逆推猜测代替输入。
- [ ] 对新候选所有 GIR 文档逐项审阅来源、引文、版权/许可原文及适用范围，包含已观察到的 GNU C Library manual 来源；保留旧 GLib/FileError 局部对应及未知历史，不能只做关键词扫描、统一贴仓库 MIT 或删文档来消除义务。
- [ ] 区分当前 native 库目标、生成/外围输入与完整源包分发义务。GIR 不在当前库图不能用于豁免完整源包中的必要材料，gir 仓库 MIT 不能自动覆盖其他来源。
- [ ] 新 supplement 的完整清单、来源回执、摘要、执行位与原输入保护可复核；缺供应材料、内容漂移和未知转换均保留失败/阻断结果。
- [ ] 输出每项对应状态与实际分发条件。当前新候选必需供应/转换/引文或当前复制生成条件仍有缺口时保持 PARTIAL/BLOCKED；后续构建/分发证据挂到对应 Gate；不得补造历史来源或宣称完整许可已通过。

- [ ] 对本工单中新生成的对象，在同一固定环境的两个独立目录实际生成，完整输出集合与字节一致；输入、工具、配置、环境和输出身份均有回执，不能仅复制旧结果或删除未知字段后比较。
- [ ] 逐项解释旧新差异，材料阶段可观察的内容、结构和接口兼容检查通过；依赖真实应用构建/Pi/资源运行的证明挂到 G2-00-04，未执行不记 PASS。
- [ ] 通过现有材料 CLI 的最高可行公开入口，完成双 Node 校验、实际禁网/同策略网络负例及受影响的缺输入、漂移、未审核 overlay、用途或别名拒绝；全部失败留证，Standards 与 Spec 分别记录。

## 新候选与阶段关闭边界

本次修订采用已确认的新可复现候选路线：优先保持现有组件版本，固定来源/工具/配置/环境并实际生成；允许新旧输出不同，逐项解释差异并验证本阶段可观察的内容、结构及接口兼容。新输出使用独立身份；保留旧候选、原完整材料、历史 UNVERIFIED 和失败记录，不裁剪源树/vendor/必要声明来消除缺口。组件版本、功能范围或接口合同若必须改变，先单列影响再确认。

本工单关闭须满足当前候选的所有材料完成条件及当前复制/生成必需条件。每项后续义务绑定对象身份、原文、拟用途、适用前提、所需证据与具体 Gate：新 kit 总核验归 #23，真实应用构建及其条件证据归 G2-00-04，最终包/默认发行/ledger/双 SBOM/notices 与分发履行归 G2-00-05，隔离 Full 与发行核对归 G2-00-06。属于当前动作的前提不可推迟；属于后续事件的证据保持待验并明确交接。材料切片通过不把整体许可 INCOMPLETE、实际分发或 Full 改为 PASS。
