## 已确认的方向

- 用户明确选择：先把 WebUI 做得更好，再进入第三阶段 Electron；当前暂停 3A 推进，开展文档辅助讨论。
- Q1：日常使用顺手优先，重点打磨提需求、查看执行进度、审查修改、失败恢复和继续任务的完整过程。
- Q2：保留 Glacier 的配色、字体和质感，允许按真实工作流重组面板、导航及操作位置。
- Q3：打开已停止的历史会话后默认继续当前会话，新建会话使用独立按钮；保留账号、模型检查及不恢复历史授权的边界。
- Q4：任务进度与关键结果优先，先显示正在做什么、需要用户处理什么；工具与命令按需展开，进度须有真实事件依据。
- Q5：接入项目内文件引用、图片与附件，覆盖代码、报错截图、设计图和说明文档；具体类型及处理边界已由Q7/Q10/Q12/Q19细化。
- Q6：即时补充与排队两种操作均纳入，由用户明确选择调整当前任务或留到完成后处理；生效边界见 Q9。
- Q7：本轮附件范围包含图片、文本/代码、PDF 与 Office；用户接受更大的实现和维护范围，读取深度见 Q10。
- Q8：任务完成后提供结果摘要与统一差异审查，展示修改文件、验证结果和遗留问题，可进入侧栏或编辑区逐文件检查；不改变既有写入审批规则。
- Q9：即时补充在下一可接收位置生效，当前工具继续；立即终止使用独立停止按钮。显示已收到/待生效，不能把接收当执行。
- Q10：现代格式内容读取优先，覆盖文字型 PDF、DOCX/XLSX/PPTX 的文字、表格及位置来源；不承诺原样版式、扫描识别或复杂图表理解。不运行宏，加密及旧版 DOC/XLS/PPT 明确不支持。
- Q11：加入分区与基础会话管理，并包含消息全文检索和从历史消息派生会话分支；分区不创建运行环境，归档不删除磁盘历史。
- Q12：引用/附件采用卡片预览，显示解析状态与范围；普通发送不增加逐次确认，超限或解析不完整时要求明确选择范围，不静默截断或丢弃。
- Q13：任务＋会话完整用量视图，包含请求/工具、token、缓存、上下文、速度和估算费用，主 Agent 与子代理可分开查看；真实来源缺失需解释，不伪装账单。
- Q14：已有能力管理纳入，包括实际扩展/技能的查看、配置与启停；安装市场仍延后。具体作用域与生效时机见 Q17。
- Q15：采用对话优先的简洁布局，右侧默认收起，文件、审查与编辑按需展开，减少常驻信息；不将推荐的常驻三栏及其附带操作自动当成用户选择。
- Q16：支持项目命令与本机网页预览，可配置测试/构建、启动并查看结果；独立探索合并到首页任务建议，保持项目协调和进程管理。
- Q17：GUI 采用一套默认设置，项目允许例外覆盖；后续执行生效，正在执行的任务不热切换，CLI/TUI 原配置独立，必需权限/协调组件不提供关闭开关。
- Q18：本机持久保存草稿、附件与队列，刷新恢复；Host存活时仍显示真实运行，失败/Host重启后队列暂停，核对状态后继续，不自动重放写入或付费任务。队列可编辑/删除，失败显示已完成步骤及恢复入口。
- Q19：按会话保留实际发送的内容快照与来源，原文件后续改变不改写历史；归档保留，提供存储查看/显式清理，清理后标记不可用。
- Q20：分批验证＋最终日常验收；代码/接口、Ego页面操作及安装态分别留证，完成已选范围并核对实际使用体验后再进入Electron。
- Q21：必须支持预览运行时 Agent 继续修改项目；先验证独立受管预览服务的写入边界、生命周期与热更新，不成立则明确记录阻断，不静默改为轮流使用或仅静态预览。
- Q22：仅分支对话及到指定位置的附件引用，继续使用当前项目文件；原会话保留，不回滚代码、不创建独立Git目录、不继承写入授权，历史费用不重复计入新消费。
- Q23：准确，按此生成详细计划；将已选范围拆成可执行Task、前置依赖、逐批验收标准和风险预案，并落盘相关文档。用户确认U0–U6顺序，全部完成后进入Electron。
- 既有 M1/M2 验收结论及其限制保留。本轮追加的优化目标不能倒写为历史验收已完成的功能。
- 沿用 React + OMP Host + Pi RPC → Electron 总体路线、本机单用户与中文产品边界。尚未提出改变运行核心或扩展平台范围。
- 本轮使用 `grill-with-docs` 的 `grilling` 与 `domain-modeling`：用交互卡片逐轮决策，记录实际答案；推荐、预选和未回复均不视为用户决定。
- 本次交付为讨论及详细计划。功能范围与实施顺序已确认；新增真实验收预算在计划中单列建议，尚未获调用授权，不启动产品代码修改或模型请求。
