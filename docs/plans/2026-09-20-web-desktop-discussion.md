# OMP WebUI / Desktop 开发计划讨论记录

状态：讨论已收敛，用户已确认共同理解；文档已同步，产品实施尚未开始。日期：2026-09-20。

执行计划见[完整三阶段开发与自动验收计划](2026-09-20-omp-webui-desktop-plan.md)。本记录保留实际选择，推荐答案不替代用户提交的答案。

## 总体路线

- 总体技术路线：React + OMP Host + Pi RPC → Electron，见 [ADR-0014](../decisions/ADR-0014-webui-to-electron.md)。
- 按三阶段开发与验收，必需门禁通过后自动继续；不是阶段末默认等待人工批准。
- 首版中文、本机、自用；GUI 多账号、基础编辑器与人工终端均在范围内。
- 第三阶段交付 macOS Apple Silicon 自用测试包；公开预览、签名公证及其他新增平台后续安排。

## 设计决策树

```text
选定总体架构（已确认）
├─ 用户与交付范围：先自用、本机、macOS 优先（Q1–Q3、Q20）
├─ 执行与验收：用户 + Codex、无硬期限、自动门禁（Q4–Q5、Q15）
├─ 生命周期：页面关闭可继续、同项目单写、停止后续接（Q6–Q8）
│  └─ 人工与 Agent 轮流写、终端存活独占（Q12、Q19）
├─ 界面：三栏、基础编辑器、人工终端、中文（Q9、Q11、Q13、Q17）
│  └─ K3 可选，不可用则当前 Codex 继续（Q16）
├─ 账号：GUI 完整管理、同 Provider 多账号（Q10、Q18）
│  └─ 会话显式选择、先覆盖 GUI（Q21–Q22）
└─ Pi：第一阶段隔离验证 0.85.1 后升级（Q14）
```

上述产品决策已确认；技术风险转化为开发计划中的验证批次，不代表已经通过实现验收。

## Q1–Q22 最终选择

| 编号 | 决策 | 用户实际选择与约束 |
| --- | --- | --- |
| Q1 | 首期受众 | 先自用再预览；先满足本人日常编程 |
| Q2 | WebUI 访问 | 仅本机；远程另设里程碑 |
| Q3 | 桌面平台 | macOS Apple Silicon 优先；保持 Linux CLI，Linux GUI 后续 |
| Q4 | 开发安排 | 用户负责产品决策，Codex 实施；无硬上线日期 |
| Q5 | 阶段验收 | 通过约定门禁后自动继续，不逐阶段等待人工批准 |
| Q6 | 关闭页面 | Host 存活时已授权任务继续；新审批等重连；退出 Host 取消，重启授权失效 |
| Q7 | 并行范围 | 跨项目并行，同项目单写，并与 CLI 协调 |
| Q8 | CLI 衔接 | 共享历史，只续接已停止会话；重新申请编程授权 |
| Q9 | 界面形态 | 三栏编程工作台；小窗口可收起侧栏 |
| Q10 | 模型配置 | GUI 完整账号管理，包含 API Key、Provider 配置和受支持 OAuth |
| Q11 | 编辑与终端 | 首版具备终端与可编辑代码，不限于预览和执行日志 |
| Q12 | 手动与 Agent | 轮流写入同一项目，切换前结束或取消当前写入 |
| Q13 | 编辑器能力 | 基础编辑与差异审查；无语言服务器、无调试器 |
| Q14 | Pi 升级 | 第一阶段验证 0.85.1 后升级；保留可回滚基线，失败不视为升级完成 |
| Q15 | 真实模型验收 | 允许复用现有路由；每阶段最多 3 个小型任务和 1 次失败重试，不开通新服务 |
| Q16 | K3 设计辅助 | K3 可选；不可用时说明，由当前 Codex 继续，不另换外部模型 |
| Q17 | 界面语言 | 首版只提供中文；英文放在后续公开预览前补齐 |
| Q18 | 账号含义 | 同一 Provider 支持多个账号，不限于一个凭据槽位 |
| Q19 | 人工终端 | 存活期间独占项目；关闭终端及其子进程后释放；页面关闭不使 Agent 自动接管 |
| Q20 | 桌面交付线 | 可安装自用测试包；签名公证与公开发布另设里程碑 |
| Q21 | 账号切换 | 每会话显式选择；停止任务后可切换；错误或额度不足不自动换账号 |
| Q22 | 多账号覆盖 | 首版覆盖 GUI，CLI 保持原默认配置；共享历史时显式选择执行账号 |

用户随后完成了第一阶段 P1-Q1–Q9 讨论并确认共同理解，见[第一阶段决策记录](2026-09-20-omp-webui-phase1-discussion.md)。这些选择细化了 Q14 的升级范围：候选技术验收之后还要升级日常 CLI，完成回滚及同候选重新应用；M1 拆为 M1-T 与 M1-I，二者均通过才完成。

第一阶段另确认沿用当前目录形成本地基线、汇总当前 Pi 会话根内全部项目、只读查看旧历史并新建分析会话、提供文件/diff/回执，以及使用栈内独立扩展副本。原 Q1–Q22 表保留当时的实际选择，不将后续细化倒写成当时已讨论的内容。

## 已核实事实与实施验证的区别

- Pi 正式 RPC 不提供完整账号管理命令；Host 需使用同版本公开 ModelRuntime 管理认证。
- Pi 公开接口支持独立凭据路径和 worker 服务注入；多个账号的集成行为仍须在第一阶段验证。
- 已找到本机 Open Design 0.21.1，但尚未确认其配置中的 K3 精确模型身份与即时可用性；按 Q16 执行显式后备方式。
- 当前 OMP 普通 RPC 仍是 headless，只读限制和 TUI 审批绑定仍在；GUI 交互宿主是待开发项。
- 当前工作树包含既有未发布安全修复；历史测试结果和源码调研不替代新 GUI 阶段验收。
- 原先 16–27 人周估算不再作为当前扩大范围的承诺；M1 后按实际集成结果重估。
