# 第一阶段工作台设计合同

受众是 OMP 的独立开发者。主要工作是在本机项目中发起只读分析，并对照历史、文件和验证证据；不是营销页面或在线聊天服务。

## 视觉方向与取舍

采用浅色、紧凑的开发工作台。六个 token：porcelain `#F6F8FC`、paper `#FFFFFF`、ink `#17243B`、muted `#526079`、focus `#245DCE`、line `#D9E0EC`。正文 PingFang SC / 系统无衬线，代码 SFMono / 系统等宽。不下载字体、图片，不引入装饰性动效库。

左对齐的项目导航 240px；中间弹性会话、正文限制约 72 字宽；右侧 320px 证据面板。小于 1100px 可折叠证据面板；小于 760px 改为项目 / 对话 / 检查三个互斥页面区域。主记忆点是中央持续可见的“只读分析”边界和与右侧源码证据的对应关系，不使用欢迎横幅、渐变英雄区或重复卡片。

```text
项目与历史 | 项目身份 / 只读边界 / 连接状态 | 文件 / diff / 回执
新建分析   | 对话正文、工具结果、运行状态   | 当前证据
历史列表   | 模型 / 输入 / 发送或取消       | 只读，不提供保存
```

设计审查：最初数据库查询返回 FAQ / 营销落地页，与本机 Agent 工作台不匹配，已舍弃；上面的 token 和布局为本项目设计。保留 skills 中稳定 key、键盘焦点、输入保留与延迟加载建议。Open Design/K3 无可用调用入口，按已接受的备用方案由当前 Codex 实现，未向其他模型外发代码。

## 行为合同

- 历史分页每次最多 50 条；工具输出按需分页，不因展开一条结果渲染全部历史。
- 新分析总是新会话；旧历史不续接。提交幂等 ID 保留到请求确定结果，不自动重发模型请求。
- 流式更新不抢焦点；读者在底部时跟随，向上阅读后提供“回到最新”。屏幕阅读器只播报状态，不逐 token 播报。
- 取消请求发出后显示“正在取消”，仅后端终态显示“已取消”；保留部分输出。
- 连接断开保留内容；重连获取新快照，有序事件缺口重新连接。Host 重启不自动恢复执行。
- 配对材料仅从 fragment 读取一次，立即清除，不进入存储；失败提示重新运行 `omp web`。
- 中文输入法组合态不发送；Cmd/Ctrl+Enter 发送，Enter 保留换行。
- 错误显示恢复动作并保留输入。空项目引导添加绝对路径；删除项目仍可看历史，不能运行。
- Markdown 禁止原始 HTML、远程图片和危险链接。文件/diff 使用纯文本，不插入 HTML。
- 按钮可见焦点、至少 44px 主操作目标；窄屏侧栏切换后焦点进入对应区域。只使用状态颜色 120ms 过渡，尊重 reduced motion。

## 验证范围

构建与类型检查、组件状态与 IME、事件重连 / 去重、真实 Host 同源配对与历史 / 文件 / diff / 模型 / 取消，使用 ego-browser 检查宽屏及窄屏。截图不替代性能或屏幕阅读器认证；性能单独记录真实测量。
