[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，2026-10-10 已发布版本；需求 US-096、US-097、US-098、US-099、US-100、US-103，门禁 GP110-05、GP110-06，必需证据 C/P/B。保留 US-001–004 及当前规格共同约束。

## What to build

用户或已授权任务按需发现可用 MCP 工具、读取允许的资源；工具列表变化、隐藏和资源返回都遵守同一权限与内容边界。

## Acceptance criteria

- [ ] 实际两种 MCP 连接贯通工具/资源发现、tool_search 或 codemode 调用、授权及有来源结果；不另建会隐式启用服务器的目录。
- [ ] direct/deferred/codemode/hidden 的配置与实际可调用状态一致；已隐藏/撤回、未知、定义变更的工具调用明确拒绝，旧授权不适用于新定义。
- [ ] 资源 URI、服务目标、权限、返回类型和大小在真实入口验证；列表或读取不扩展成本/权限，未知远端 HTML/MCP Apps 不执行。
- [ ] 服务器工具通知、重新发现、资源列表变化和调用竞态有可观察结果；静态工具缓存不代实际列表，失效回执不得冒充新能力。
- [ ] 结果超限、错误、部分内容、取消和断连都有明确状态；完整返回或临时文件的访问归属保持，不能借资源路径读取任意主机文件。
- [ ] 受控 stdio/HTTP 服务记录发现和调用数，真实 Pi 与 Ego Lite 验证允许、隐藏、热更新和拒绝旅程。
- [ ] 保存实际源码/工作树、Pi/Node/候选与输入身份、命令/退出码、失败及限制，分列 Standards 与 Spec。未运行或缺必需证据不记 PASS；实际服务、付费、安装切换另按具体任务授权。
