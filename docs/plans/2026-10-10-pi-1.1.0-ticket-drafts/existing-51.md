# U5-N02：配置可选资源并在下一次执行生效

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U5-01、U5-02，需求 US-057,US-059,US-060,US-061，并遵守 US-001–US-004。出口 G5-01、G5-02；必需证据 C/P/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户调整 GUI 默认或项目覆盖中的可选资源启停，看到待生效状态，新任务实际加载该快照，正在运行的任务保持原配置。

## Acceptance criteria

以下为 2026-10-10 总规格扩展的追加条件，原条件继续有效。

- [ ] 复用 PI110-N05 及后续模型绑定的配置版本和任务快照接口，将通用资源启停接入同一生效/冲突语义，不能复制成互相矛盾的第二套配置。
- [ ] 原 GUI 资源覆盖不改 raw Pi 原配置；新 MCP/codemode 的 OMP 受控配置按已确认范围在 CLI/TUI/WebUI 一致生效，不能把旧“CLI 不变”解释为排除该新能力。

- [ ] 页面保存、Host 原子持久化、revision、项目覆盖/重置覆盖和下一 worker 启动注入形成完整路径；覆盖删除回到 GUI 默认，不改 CLI。
- [ ] 把资源 revision 贯通任务绑定、输入账本、实际 Pi 载荷桥和加载回执，不能只把固定零值改成任意通过。
- [ ] 运行中保存只影响下一执行；页面区分请求值、待生效与实际加载值，活动 worker 不热切，启动失败不冒充生效。
- [ ] 队列绑定旧 revision 时暂停并展示差异，用户明确确认后再创建当前有效投递；重连/重复点击不变更已接受语义。
- [ ] 禁止关闭必需集合，拒绝未知来源/不兼容组合和跨项目覆盖；失败保留最后有效 GUI 配置及用户草稿。
- [ ] 实际公开 Host→新 Pi worker→加载回执→Ego Lite 读回证明启停与项目覆盖生效，并验证旧 worker 不变及原 CLI 行为。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
