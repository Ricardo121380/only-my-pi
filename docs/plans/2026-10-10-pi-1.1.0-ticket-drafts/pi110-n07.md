## What to build

用户在相同 OMP 配置和审批体验中显式连接一个远程 MCP 目标，使用受控凭据引用完成调用，并能识别断连后的未知结果。

## Acceptance criteria

- [ ] 贯通明确 URL/配置来源/凭据引用、项目覆盖、任务快照、真实 Streamable HTTP 协议请求和产品结果；旧 SSE 明确不支持。
- [ ] 目标、重定向、认证头和配置覆盖都保持已授权绑定，不将凭据交给新地址、错误项目或日志；模型上下文不取得原始凭据。
- [ ] 每次调用沿同一工具权限合同；远程服务器声明不能替权限，涉及本机项目写入仍须本机所有权和隔离，不能因 HTTP 路由放宽。
- [ ] 受控 HTTP 服务器核对收到的目标、身份和调用数；未授权、停用、撤销、错误目标和超额请求没有实际执行。
- [ ] 协议连接重试和业务工具重试区分：可能已执行的工具调用不自动重放，超时/断连/取消保留已知与未知效果，有限输入输出及截止时间生效。
- [ ] CLI/TUI/WebUI 完成配置→启用→授权→结果→断连/停止旅程；OAuth 由下一票扩展，此片至少实际覆盖受控认证引用而非仅无认证 mock。
- [ ] 保存实际源码/工作树、Pi/Node/候选与输入身份、命令/退出码、失败及限制，分列 Standards 与 Spec。未运行或缺必需证据不记 PASS；实际服务、付费、安装切换另按具体任务授权。
