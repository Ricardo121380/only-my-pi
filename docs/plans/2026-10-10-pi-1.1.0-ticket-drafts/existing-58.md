# U6-N02：验证固定性能样本与进程资源占用

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U6-02，需求 US-072,US-073,US-074，并遵守 US-001–US-004。出口 G6-02；必需证据 C/B/I。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户在长历史、大输出、检索、解析和连续预览中仍可及时输入与取消；维护者能用固定样本复验响应与资源表现。

## Acceptance criteria

以下为 2026-10-10 总规格扩展的追加条件，原条件继续有效。

- [ ] 固定负载加入有界 MCP 发现/输出、codemode 嵌套并发及分类/图片结果、预算等待与取消；保持原冻结性能目标和至少 30 个有效输入样本。
- [ ] 新增 MCP 子进程/QuickJS 与产物存储资源分列，有限并发、超时及输出额度实际生效；不把远端请求取消确认等同远端停费。

- [ ] 绑定硬件、源码/候选、前台窗口、数据集、计时口径和原始样本，至少 30 个有效输入样本，异常样本及失败不能静默丢弃。
- [ ] 10,000 事件、5 MiB 输出与长 diff 下，输入 P95 <100 ms、本地取消确认 P95 <500 ms；取消确认不冒充进程已退或 Provider 停止计费。
- [ ] 100 会话/100,000 消息的热索引检索 P95 <500 ms；连续 20 次预览变更的可见更新 P95 <2 秒，记录正确性与丢更新。
- [ ] 解析并发分别记录排队、限额、时间和资源表现，Host/worker/PTY/预览/共享浏览器内存分列，不从单 worker 结论推广总量。
- [ ] 使用绑定本批源码的候选及隔离安装取得 C/B/I 必需证据；必要性能安装是本票验证准备，不预写下一票完整 Full、兼容及回滚验收通过。
- [ ] 未达标定位并修正影响范围后重验对应样本，不降低目标后称原目标通过；保留前后原始值和证据身份。
- [ ] 完成本票必需的 C/B/I 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
