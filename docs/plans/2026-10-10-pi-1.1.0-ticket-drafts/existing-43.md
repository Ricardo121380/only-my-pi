# U3-N05：从停止会话的指定消息创建分支

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U3-03，需求 US-040,US-041,US-042，并遵守 US-001–US-004。出口 G3-03；必需证据 C/P/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户从停止会话的有效消息创建新的编程会话，保留所选消息及之前上下文和附件来源，使用当前项目文件继续工作。

## Acceptance criteria

以下为 2026-10-10 总规格扩展的追加条件，原条件继续有效。

- [ ] Pi 1.1.0 的规范上下文/usage/工具条目及 PI110-N13 会话产物进入指定消息分支；所选位置之后的产物不混入，原件、来源和共享引用保持。
- [ ] 分支不继承 MCP 工具授权、分类/生图许可、预算预占或活动连接；继承结果不重新生成、不作为新消费。

- [ ] 页面选择消息，经 Host 验证源/目标准入与锁，使用固定 Pi 公开 at-entry 分支语义生成新身份；源位置包含所选消息，不意外沿用 before 默认语义。
- [ ] 只允许有效且停止的源会话，覆盖活动 worker、CLI 占用、坏 entry、源替换及锁竞争；拒绝时没有半创建或错误释放。
- [ ] 源历史保持，新分支不建 Git worktree、不回滚项目文件、不继承编程授权、未投递队列或活动进程；账号缺失不静默回退。
- [ ] 共享附件引用仅包含分支位置已有内容，以原子引用保护避免与清理竞争；已失效材料明确显示，源/新会话身份和 lineage 可回读。
- [ ] 继承历史消费只作为来源记录，不记作新分支实际消费；具体聚合由 U4 交付，本票必须保存可追踪 lineage。
- [ ] 真实 Pi 分支与公开 Host 入口核对 entry、compaction/label、源字节及新会话继续；Ego Lite 完成创建→打开→显式准入→续接，重复操作及失败恢复受控。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
