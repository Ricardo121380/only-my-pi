## What to build

用户在 OMP 查看或显式导入本地 MCP 配置，选择项目覆盖后启用服务器，批准一次或当前任务的工具范围，取得真实只读结果并能停止服务器。

## Acceptance criteria

- [ ] 从 CLI/TUI/WebUI 配置入口到 OMP 自有持久化、项目覆盖、任务快照、实际进程与结果完整贯通；raw Pi 原配置字节保持，导入和预览均零启动/零取密命令执行。
- [ ] 命令、参数、cwd、环境与凭据引用经过受控准入；同名目标冲突、跨项目凭据、动态取密命令、任意环境继承和扩展注册的额外服务器不得绕过明确启用。
- [ ] 在明确只读范围内逐调用授权，支持仅本次/本任务复用；工具定义、目标、配置或任务生命周期变化时旧许可不放行，不信任 readOnlyHint。尚未交付的写入能力明确拒绝。
- [ ] 实际 stdio 协议服务器记录接收数及真实读取结果；未批准、撤销、无界输入输出和范围外请求均不执行，不只看调用包装函数返回。
- [ ] 启动、进程组、退出、取消与残留可回读；任务期间页面断连不误杀已授权工作，未知孤儿保持阻断，后代尚存不能释放相关持有。
- [ ] 配置变更只影响后续任务，撤销停止后续调用；从保存/启用/授权/调用/停止到重启读回的 C/P/B 证据通过，共享配置版本接口留给后续 #50–#52 复用。
- [ ] 保存实际源码/工作树、Pi/Node/候选与输入身份、命令/退出码、失败及限制，分列 Standards 与 Spec。未运行或缺必需证据不记 PASS；实际服务、付费、安装切换另按具体任务授权。
