# U3-N01：创建项目分区并持久化项目归类

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U3-01，需求 US-034，并遵守 US-001–US-004。出口 G3-01；必需证据 C/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户创建、重命名和排序项目分区，调整已登记项目归属，刷新或重启后仍能按相同组织方式找到项目。

## Acceptance criteria

- [ ] 页面操作贯通 Host 私有元数据持久化和目录列表回读；未分组项目保留明确入口，项目仍使用原稳定身份。
- [ ] 创建、重命名、排序、移动归类及重置为未分组具有确定 revision，多窗口冲突不覆盖他人已保存结果。
- [ ] 分区操作不移动项目目录、不改变会话文件、账号或编程授权；切换分区不会自动启动任务。
- [ ] 覆盖空名称、重复显示名、已移除项目、损坏元数据、写入失败、重启及迟到响应，原数据保留且错误可恢复。
- [ ] 最高公开接口和 Ego Lite 核对实际保存、刷新、排序与项目打开；前后目录及 Pi 历史字节保持，现有导航和草稿隔离回归通过。
- [ ] 完成本票必需的 C/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
