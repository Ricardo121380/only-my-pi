# U3-N02：重命名、置顶、归档和恢复会话

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U3-01，需求 US-035，并遵守 US-001–US-004。出口 G3-01；必需证据 C/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户整理会话列表，归档后仍可显式找到并恢复原会话，已有任务和执行历史保持原身份。

## Acceptance criteria

- [ ] 从会话菜单到 Host 元数据、列表投影和重启读回完整贯通重命名、置顶、归档/恢复；不通过重命名或移动 Pi 文件改变 sessionKey。
- [ ] 活动与归档状态清楚，归档不删除历史、材料或停止正在运行的任务；打开恢复后的会话仍重新做既有准入检查。
- [ ] 归档过滤、排序及名称冲突有确定呈现，旧无元数据会话可以兼容读取，不覆盖原历史头或内容。
- [ ] 多窗口 CAS、历史被删/损坏、写入失败、切项目及迟到列表响应可解释，草稿不会被另一个会话替换或误发送。
- [ ] 公开接口与 Ego Lite 验证保存、刷新、归档查找和恢复路径，核对原历史、共享附件及任务状态保持。
- [ ] 完成本票必需的 C/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
