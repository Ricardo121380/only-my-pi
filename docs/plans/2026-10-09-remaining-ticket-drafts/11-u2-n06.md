## What to build

用户上传 DOCX，按标题、段落或表格查看和选择内容，模型收到与页面范围对应的冻结文本。

## Acceptance criteria

- [ ] 复用已通过实际 PDF 路径的有界 worker/材料接口，交付 DOCX 上传、结构解析、局部选择、卡片、真实 Pi 发送及历史核对。
- [ ] 保留标题、段落、表格/单元格等真实结构定位；没有可靠页码时不生成假页码，空内容及部分提取可解释。
- [ ] 通用配额、文本 2 MiB、实际展开 200 MiB、ZIP 10,000 条目、30 秒和 512 MiB 采样 RSS 在实际公开路径生效；边界及 +1、损坏压缩包覆盖。
- [ ] 宏、嵌入脚本、外部关系/远程资源不执行或联网；加密、旧 DOC、伪装格式明确拒绝并保留草稿。
- [ ] 选定结构的文本与真实 Pi 输入逐项对应；超上下文、partial、取消、刷新、worker 失败不静默漏内容或自动重试执行。
- [ ] 双 Node 解析及负例、实际 Host/Pi 路径和 Ego Lite 选择到历史旅程分列留证；不回归破坏已交付 PDF 与纯文本输入。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
