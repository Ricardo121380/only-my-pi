# U3-N04：增量更新、取消和重建全文索引

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U3-02，需求 US-038,US-039，并遵守 US-001–US-004。出口 G3-02；必需证据 C/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户在持续新增历史时获得可解释的最新搜索结果，可查看进度、取消或重建索引，并识别陈旧和损坏部分。

## Acceptance criteria

- [ ] 在已能查询与定位的路径上接入新增/变更/删除历史的增量更新，索引与原数据身份关联，完成一批后原子发布可查询版本。
- [ ] 从页面显式启动、查看范围/进度、取消与重建；后台工作有界且不阻塞输入，取消后已有效结果与未完成范围分列。
- [ ] 源损坏、历史删除、部分不可读、worker 退出、重启及重复重建不伪装完整结果、不删除原历史，保留重试或人工处理入口。
- [ ] 变化期间点击旧结果须重新核对 entry 与源身份；不定位到同序号但不同内容的消息，权限和范围不能因缓存扩大。
- [ ] 固定语料比较增量结果与从相同源完整重建的可观察结果，核对新增、删除、损坏和恢复；性能原始样本保留并交给 U6 的冻结性能门禁。
- [ ] 实际 Host 和 Ego Lite 完成重建→取消→恢复→搜索→定位旅程，旧正确结果和材料引用保持。
- [ ] 完成本票必需的 C/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
