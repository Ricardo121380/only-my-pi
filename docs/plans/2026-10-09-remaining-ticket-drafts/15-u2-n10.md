# U2-N10：验收混合材料的发送、排队与安装态旅程

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U2-06，需求 US-017–US-033，并遵守 US-001–US-004。出口 G2-01、G2-02、G2-03、G2-04、G2-05、G2-06；必需证据 C/P/B/I。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户在同一会话混合文本、引用、图片和四种文档，完成发送、补充、排队、刷新、重连及历史核对，安装态也能使用相同资源。

## Acceptance criteria

- [ ] 用实际 Host→固定 Pi→本地受控模型贯通混合材料，核对每张卡片范围、材料版本、inputId、模型请求、消费回执和历史的对应。
- [ ] 覆盖即时补充、FIFO、编辑/移除未投递项、取消、身份/配置变化、多窗冲突和确认丢失；未知状态先回读，既有授权与恢复约束保持。
- [ ] 所有选定格式、通用/格式上限、上下文超限、partial、坏数据和资源缺失的跨类型组合保持真实拒绝，不通过逐文件拆请求逃避整批限额。
- [ ] Ego Lite 完成上传/引用→选择范围→发送→排队→刷新→历史→清理旅程，包含键盘与失败恢复；组件 mock 不代实际页面。
- [ ] 在绑定本批源码的隔离候选包内运行解析资源与混合旅程所需路径，证明确切加载路径、断网可用和没有 checkout/全局回退；沿用 G2 来源证据须核对身份仍匹配。
- [ ] 核对 G2-01–G2-06 全部必需层，受影响完整回归、Standards/Spec 与证据映射完成后才关闭 U2 阶段；真实外部 Provider 和日常晋升留在 U6。
- [ ] 完成本票必需的 C/P/B/I 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
