## What to build

用户跨已登记项目搜索名称和用户/助手消息，查看匹配片段与来源，点击后打开准确会话和消息位置。

## Acceptance criteria

- [ ] 索引范围仅已登记项目的可读取用户/助手消息，保留 U1 输入载荷的真实用户语义；不扫描全盘、凭据、隐藏推理、工具二进制或未约定日志。
- [ ] 查询返回项目、会话、时间、entry 定位、片段和覆盖范围，支持名称及归档过滤；从结果打开、分页定位与导航迟到响应保护贯通。
- [ ] 不能直接把已截断的历史展示投影当完整全文源；长消息匹配能核对原有效消息及分支语义，引用未收录范围时状态明确。
- [ ] 首片提供有界建立/刷新可查询索引的实际入口；源变更、删除或损坏时至少使受影响结果失效并提示陈旧/不完整，禁止旧结果冒充当前完整。
- [ ] 空查询、无结果、不合法范围、缺失 entry、重复点击和索引不可用有真实可恢复状态，不为打开搜索结果误发模型任务。
- [ ] 公开查询与 Ego Lite 使用固定语料核对命中、漏收录说明、归档过滤、长消息片段和消息定位；原历史不被改写。
- [ ] 完成本票必需的 C/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
