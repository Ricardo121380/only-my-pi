## What to build

用户显式启动受支持配方的受管预览，Agent 修改项目时页面持续更新，且预览不能写回源项目或取得 Host 凭据。

## Acceptance criteria

- [ ] 把已验证配方接到生产 Host supervisor、持久状态和 UI，明确支持的项目/文件规则及真实本机来源；不把仅三文件的 synthetic PoC 当一般项目已支持。
- [ ] 源读取、同步镜像、缓存与派生输出的边界有实际证据；误写原项目、链接替换、未允许输入和向源写回均拒绝，不建 Git worktree。
- [ ] 真实受控 Agent 与预览同时运行，多次源变更能在页面看到正确新内容；命令/终端/人工入口的单写规则保持。
- [ ] 首片就完成凭据与来源隔离：环境、Cookie/Authorization、请求/响应头、HTTP 及 WebSocket 代理和重定向受限，不允许任意 URL 代理。
- [ ] 实际覆盖 localhost 与 127.0.0.1 的配对后泄漏、服务端伪造 Host/Origin/协议头重放 HTTP/WS 负例，不能仅凭端口不同或浏览器 CORS 宣称安全。
- [ ] 显示启动/端口冲突/运行/停止/失败与重连状态；关闭面板不杀服务，停止及 Host 退出核对子进程后再释放；未知残留在此片就保守阻断。
- [ ] 首页预览/探索建议触发真实已支持入口；Ego Lite 核对并行修改、更新、重连、停止与受限嵌入，必要独立标签仍绑定同一受管来源。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
