# U2-N05：选择 PDF 页并经有界解析发送

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U2-04，需求 US-023,US-027,US-028,US-029,US-030，并遵守 US-001–US-004。出口 G2-03、G2-04；必需证据 C/P/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户上传文字 PDF，查看实际页位置和解析状态，选择页范围后把确切内容发送到 Pi；此首个文档切片同时建立共享的有界解析与材料发布接口。

## Acceptance criteria

- [ ] 从页面上传到独立受限进程解析、页范围选择、冻结、真实 Pi 输入及历史完整贯通；绑定已验收 worker、辅助模块、字体/CMap/WASM 和资源身份。
- [ ] 共享文档解析生命周期以本 PDF 路径实际使用：输入、进程、预算、结果/partial、位置、取消及清理均可观察；不新建只有接口而无人调用的基础层工单。
- [ ] 实际执行 PDF 200 页、文本 2 MiB、累计展开 200 MiB、30 秒、512 MiB 采样 RSS 及通用上传配额；覆盖单流/多页、过滤器数组、缓存、恢复及重置，不把 RSS 采样称为 OS 硬上限。
- [ ] 损坏、扫描/空页、加密和部分解析明确区分；不运行文档动作、脚本或远程资源，真实网络拒绝及缺资源/资源漂移可核对。
- [ ] 页位置、所选文本和发送快照一致；上下文超限要求选择更小范围，未知容量明确，partial 未经明确处理不冒充完整。
- [ ] 取消、超时、解析进程退出、重复材料和刷新保持 Host 可用、旧草稿完整并确认子进程/临时对象归属；Node 22.19.0/24.19.0、真实 Pi 与 Ego Lite 的本路径必需证据分别记录。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
