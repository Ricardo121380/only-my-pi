## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U5-02，需求 US-058,US-060,US-061，并遵守 US-001–US-004。出口 G5-02；必需证据 C/P/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户为声明配置 Schema 的已有资源编辑参数，明确看到校验、待生效、实际加载或失败，并能恢复最后有效配置。

## Acceptance criteria

- [ ] 由资源声明生成受支持的配置表单，完整贯通输入校验、持久 revision、下一 worker 加载与实际值反馈；无 Schema 明确不支持通用编辑。
- [ ] 不提供任意代码执行配置框，不把 Provider 凭据混入普通配置；账号秘密仍走已有账号入口且不进日志、模型或页面持久存储。
- [ ] 非法值、Schema/资源版本漂移、加载失败、配置冲突和重复保存有公开拒绝及恢复路径，最后有效 GUI 配置保留。
- [ ] 启用新配置期间不热改活动 worker；旧 revision 队列暂停、用户处理后再投递，失败与重启不能隐式放行。
- [ ] 通过真实 Pi 运行回执核对请求值与实际加载值，Ego Lite 完成配置→下一任务→失败→恢复旅程。
- [ ] 本票与 [U5-N02 / #51](https://github.com/Ricardo121380/only-my-pi/issues/51) 全部完成后才关闭原 U5-02，C/P/B 与受影响 U1 输入/账号/权限回归分别留证。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
