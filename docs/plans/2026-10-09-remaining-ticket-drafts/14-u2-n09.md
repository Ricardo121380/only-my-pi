# U2-N09：查看发送快照并安全清理材料存储

状态：OPEN；分流标签：ready-for-agent。执行前核对全部前置和操作条件。

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U2-05，需求 US-030,US-031,US-032，并遵守 US-001–US-004。出口 G2-05；必需证据 C/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户能区分原上传、解析结果和已发送内容，查看各自空间与引用，明确确认影响后清理可删除材料，同时保留共享历史。

## Acceptance criteria

- [ ] 统一展示各已交付材料类型的原件、解析物、实际发送版本、摘要、解析器/资源身份和选择范围；延续首个材料切片已有的不可变快照，不重写旧消息。
- [ ] 修改或删除项目原件后仍可核对已发送内容，归档不删除材料；读取已清理内容时给出明确不可用标记。
- [ ] 按消息/会话及共享引用核算清理影响，给出待删对象与受影响引用再由用户显式确认；共享对象仍被引用时不得误删，不删除项目原件。
- [ ] 清理与新发送、草稿移除、恢复及未来分支引用取得之间保持原子引用保护；本票用共享引用验证边界，实际指定消息分支旅程在 U3 验收。
- [ ] 磁盘不足、部分删除失败、崩溃及重新打开时保留旧历史和未完成操作状态；不自动删历史补空间，不将未知删除状态报为成功。
- [ ] 从实际存储页与 Host 公开入口验证查看、选择、确认、删除、失败和读回；核对真实文件及其他会话引用未受损。
- [ ] 完成本票必需的 C/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
