# U2-N07：按工作表和单元格选择 XLSX 内容并发送

## Parent

[总规格 #19](https://github.com/Ricardo121380/only-my-pi/issues/19)，原 Task U2-04，需求 US-025,US-027,US-028,US-029,US-030，并遵守 US-001–US-004。出口 G2-03、G2-04；必需证据 C/P/B。C 为合同/本地服务，P 为固定 Pi 与本地受控模型，B 为 Ego Lite 实际页面，I 为实际隔离或日常安装，L 为实际外部 Provider；各层分别留证。

## What to build

用户上传 XLSX，选择工作表或单元格范围，区分公式文本和已有缓存值，并核对实际发送的表格内容。

## Acceptance criteria

- [ ] 复用有界文档接口贯通上传、工作表/单元格定位、局部范围预览、冻结、真实 Pi 发送和历史。
- [ ] 公式文本与已有缓存值分列，缺缓存值如实显示；不计算公式、不运行宏或访问外部链接。
- [ ] 200,000 非空单元格、通用上传配额、文本 2 MiB、实际展开 200 MiB、ZIP 10,000 条目、30 秒和 512 MiB 采样 RSS 在实际入口生效。
- [ ] 覆盖损坏、加密、旧 XLS、伪装类型、空表、稀疏表、边界/+1 和部分提取，用户能理解实际可选范围及缺失内容。
- [ ] 选定单元格、值的表示方式、摘要与模型实际输入一致；超上下文要求用户缩小范围，不静默截断，取消/刷新/失败保留草稿。
- [ ] 双 Node、公开 Host/Pi 与 Ego Lite 的代表性正常及负例通过，旧格式的未支持状态不会展示成已成功解析。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
