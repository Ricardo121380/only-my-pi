## Parent

## What to build

用户上传 PPTX，按真实幻灯片位置查看和选择可提取内容，发送后能从历史核对相同范围。

## Acceptance criteria

- [ ] 贯通上传、有界解析、幻灯片位置/范围选择、材料卡片、冻结、真实 Pi 投递和历史来源，不伪称图表语义或扫描图已识别。
- [ ] 200 张幻灯片、通用配额、文本 2 MiB、展开 200 MiB、ZIP 10,000 条目、30 秒和 512 MiB 采样 RSS 实际生效并覆盖边界/+1。
- [ ] 保留真实幻灯片顺序与位置，空页、部分提取及不支持内容分别显示；所选文本不能混入未选择页。
- [ ] 宏、嵌入脚本、文档动作和远程资源不执行；损坏、加密、旧 PPT 和类型伪装明确拒绝。
- [ ] 上下文超限、解析失败、取消或重连保留输入并要求明确处理，不静默丢页或自动换模型/重发。
- [ ] 双 Node 的解析矩阵、真实 Host/Pi 输入核对与 Ego Lite 旅程分别留证，保留其他已交付格式的回归。
- [ ] 完成本票必需的 C/P/B 证据；按公开行为测试，保存源码/工作树、输入/运行身份、命令/退出码及失败，分别给出 Standards 与 Spec 结果。所有必需条件满足才关闭本票；原 Task 全部映射子项完成才迁移其状态。
