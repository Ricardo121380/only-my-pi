**历史使用基线（M2，2026-09-26）：** 当时日常 OMP 安装源码 `9130d02` 的 Full 栈，使用 Pi 0.85.1 / Node 24.19.0，并验证了 **CPAR Grok 4.5 / cpar-grok-build / low** 的小型修改与受管 writer。该记录不证明当前安装或服务可用。下列操作说明保留 M2 已交付使用方式；后续连续输入、MCP、分类与生图的范围另见蓝图所链接的验收记录，完整 WebUI 尚未交付。[M2 完成验收与限制](plans/2026-09-26-omp-webui-phase2-closeout.md)

```sh
omp web
omp web status --json
omp web stop --json
```

`omp web` 启动同一配置目录下的单实例 Host，并打开一次性配对链接。链接两分钟后失效；页面提示配对失效时重新执行命令，不要分享链接。Host 仅监听 `127.0.0.1` 的动态端口，不用于远程部署。`omp -- web` 仍将 web 当普通 Agent 任务文本。

## 使用

1. 从当前生效 Pi 会话目录汇总项目，或点击“添加”输入本机绝对路径。不会扫描整个用户目录。
2. 选择历史查看正文；每页最多 50 条，工具输出按需读取。查看本身不续接。需要继续时显式续接已停止的会话，绑定运行账号；旧编程授权不会恢复。
3. 在“外观与设置 → 账号与模型”管理两端共用的产品账号，CLI 创建的账号与认证状态也在这里读取。也可明确选择“CLI 配置（只读引用）”：后者允许任务使用原配置，GUI 不修改其凭据；失败不自动换账号。选择模型和支持的思考强度，默认执行模式仍为只读分析。活动账号和登录操作通过跨进程占用协调；另一端尚未退出时，修改、删除、登录及登出会明确拒绝。
4. 需要修改项目时选择“受控编程”。选择模式不等于批准写入；运行时展示具体计划、范围与验证操作，逐项批准后执行，也可撤权。受管 writer 的补丁应用和真实工作区验证分别记录。
5. “取消任务”先变为“正在取消”，进程退出确认后才进入终态。关闭页面不停止任务；刷新重连恢复显示；`omp web stop` 停止 Host 管理的任务与终端。
6. 右侧“打开编辑工作区”提供 Monaco 文件树、多标签、搜索与 diff。显式进入手动编辑才取得项目所有权；保存检查内容版本，遇到外部修改先重新读取或合并。草稿只在当前页面，刷新前需保存。
7. 底部“输出与终端 → 终端 → 启动终端”创建真实本机 shell。终端存活期间占用项目写入；隐藏或刷新不结束它，通过“结束终端”确认清理。使用本机用户权限，启动时不自动加载 shell 配置，不能当作安全沙箱。
8. 用量来自当前任务的实际模型回执；强度选择用于下一条消息，不修改 CLI 默认值。缺失 token/价格显示未知，估算费用不是账单，子代理预算与主 Agent 用量分开查看。

键盘：Enter 换行，Cmd/Ctrl+Enter 发送；输入法候选确认不会发送。工具输出、代码和 Markdown 都是展示数据，不是授权指令；远程图片不自动加载。

## 限制与故障

- 同时最多 4 个任务，保留最多 1000 个任务去重记录；只读任务最长 15 分钟。达到容量时明确拒绝，不自动丢弃去重记录。
- 文件预览最多 512KiB；符号链接、典型凭据文件、`.git` 和 `node_modules` 不提供预览。Git diff 禁用外部 diff/textconv/filter，不含未跟踪文件。
- Host 重启使浏览器授权失效，不自动重复模型请求。可确认已停止的任务按中断处理；受控孤儿进程或清理不明时拒绝恢复，保留所有权供核对。完整历史仍由 Pi 会话文件保存；Host 仅保存有界显示检查点。
- 项目不可访问时仍可看历史。模型列表为空时先确认已明确选择账号，再检查 GUI 账号凭据或 CLI 配置；不会借用其他账号补齐。
- `OWNER_RECONCILIATION_REQUIRED` / `ORPHAN_WORKER_REQUIRES_RECONCILIATION` 表示无法安全证明旧进程已退出。不要删除锁或对未知 PID 强杀；先核对 `omp web status` 与对应进程身份。
- 同项目单写覆盖受支持的 OMP CLI/GUI/人工模式；raw Pi、外部编辑器及任意守护进程不受此协议保证。终端是本机协作式进程管理，不承诺恶意进程隔离。
- OAuth 的替身合同测试与真实 Pi / 本地受控 OAuth 流程分别记录；受控验证不证明外部 Provider 已通过互操作。附件、插件市场、分区管理等标记“尚未接入”的入口不属于已交付能力。

## 开发验证与回滚

```sh
npm run build:web
npm run test:web
npm run test:host
npm run typecheck
node scripts/phase1-gates.mjs /absolute/evidence-directory
```

最终候选打包会从清洁源码重新构建前端，并携带实际打包依赖及许可证。浏览器验收使用 Host 同源构建产物，不以 Vite 开发服务器代替认证验收。

日常 Full 栈回滚属于整个运行栈事务；不是 npm 安装或仅 Harness 回滚。先检查 `omp admin stack rollback --plan --json` 的目标是否为本次升级前 active，再按已审核回执操作。未确认旧栈身份、存在用户活动会话或进程归属不明时，停止切换。2026-09-26 实际升级、回滚与重新应用见[第二阶段完成记录](plans/2026-09-26-omp-webui-phase2-closeout.md)；旧[M1记录](plans/2026-09-20-omp-webui-phase1-progress.md)保留历史口径。
