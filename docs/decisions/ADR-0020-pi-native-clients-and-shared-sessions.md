# ADR-0020: 以 Pi 为共同内核交付 CLI 与桌面，并支持显式账号下的会话交接

用户确认 Only my pi 是直接基于最新稳定版 Pi 的产品，CLI/TUI 与桌面都是正式客户端。图形端先完成全部已选 WebUI 范围和日用验收，再进入 Electron；CLI 持续独立交付。两端共享同一项目的会话查看和接续能力，同一会话同一时刻只由一端执行；已有同项目单写规则继续有效，跨项目并行不受此决定取消。

2026-10-18 Q11 补充平台范围：首批新增账号、共享配置、材料输入与会话接续在 macOS Apple Silicon 完成核心能力对等；Linux CLI 继续维护现有能力，新增能力随后独立适配和验收，不作为 macOS 首版 WebUI/桌面出口的前置。既有 Linux CLI 兼容与受影响回归仍保留。

Pi 继续拥有 Agent loop、模型、工具执行与会话历史。产品只补必要的交互、项目组织、账号绑定、授权和本机集成；优先复用公开 CLI/SDK/扩展接口。现有 Host/worker 名称和进程划分不构成必须保留的产品要求；SDK 直接嵌入与 RPC 子进程按实际行为、生命周期及隔离需求比较，不在本决定中预先合并或删除进程。

## 已选行为

- 两端以核心编程能力对等为首个完整版本的条件：相同产品账号、会话、已选工具和材料都能用于编程。项目整理、可视化审查和预览采用各端适合的交互；不要求把每个 GUI 操作复制为 CLI 命令。产品配置共享与独立设置入口见 [ADR-0021](ADR-0021-shared-product-configuration.md)。
- CLI 可以独立新增、登录、显式选择并使用产品账号，配置 MCP 与已选工具，无需启动 Only my pi WebUI/桌面；认证需要时可以打开服务商网页。复用既有账号身份和存储归属，不复制产品凭据去覆盖原 CLI 默认配置，不把同 Provider 的两个账号合并。
- 两端查看同一历史；只接续已停止、可读且未被占用的会话。接续时核对项目、会话和账号身份；旧历史缺少绑定时要求显式选择，已有绑定不可用时停止自动续接。沿用 ADR-0015：任务及其进程完全停止后，用户可以显式切换账号并重新选择模型、验证授权；新任务记录新绑定，旧任务与历史调用归属保留。会话恢复或账号错误本身不触发切换。
- 客户端交接不恢复原编程授权、待审批答复、排队操作或未知外部效果。目标端重新完成当前运行所需的准入和授权。
- 同一会话的占用、项目写入所有权、账号变更与活动使用协调必须覆盖 CLI/GUI 的真实进程；只在单个 Host 内存中协调不足以满足新增跨端使用。
- 自定义会话目录采用明确的登记/选择范围，不为实现互通扫描整个用户目录。版本不兼容、路径失效和未知残留明确拒绝或保持只读。
- 首版跨端接续只保证配套的已验收运行组合，记录 CLI、图形端、Pi/扩展及相关数据合同身份。未验证组合仅能查看可读历史并提示匹配版本，不执行续接、静默迁移共享数据或自动改变另一端安装；读不懂的历史保留原件并说明原因。

## 取舍与后继关系

相较于两端各自保存会话和账号，这一选择增加了身份解析、旧历史兼容及跨进程协调工作，换来用户可在终端和图形端之间连续工作。会话数据的权威仍属于 Pi，产品索引与控制状态不能成为另一份独立对话历史。

2026-10-17 设计质询澄清：此前“已有绑定不可用时提示恢复原账号、不以另选账号覆盖原归属”的措辞容易被读成会话永久绑定，现按 ADR-0015 和已存在的 GUI 路径澄清为“禁止自动切换、允许停止后显式切换并保留历史归属”。源码依据为 [GUI 账号选择](../../webui/src/App.tsx)、[每任务账号绑定](../../packages/host/tasks.mjs)和[历史绑定追加](../../packages/host/account-rpc-entry.mjs)。本次为静态核对，没有新增跨端切换运行验收。

本决定补充 [ADR-0013](ADR-0013-direct-terminal-coding-agent.md) 的 CLI 产品入口，部分更新 [ADR-0014](ADR-0014-webui-to-electron.md) 的固定接入拓扑，以及 [ADR-0015](ADR-0015-gui-account-isolation.md) 中“CLI 多账号入口不在首版范围”的历史限定。账号隔离、[项目所有权](ADR-0016-host-lifecycle-and-project-writer-ownership.md)、[运行栈与安装](ADR-0017-versioned-runtime-contracts-and-stack-promotion.md)、[输入确认](ADR-0018-host-input-ledger-and-pi-correlation.md)的行为约束保留。

这是已确认的产品与架构目标，**不是双端账号/会话互通已实现或已验收的声明**。源码核查发现 CLI→GUI 历史接续已有路径，GUI 自有账号→CLI 的对称选择/恢复仍有缺口。完整路线、讨论选择和待实施切片见[开发蓝图](../plans/2026-10-17-product-direction-and-iteration-plan.md)；不在本决定中重建任务编号或改变远程依赖。
