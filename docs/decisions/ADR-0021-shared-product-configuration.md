# ADR-0021: 两端共用产品配置，并独立完成设置和认证

用户在开发蓝图 Q8/Q9 确认：Only my pi 自己管理的工具/技能设置及分类、生图模型绑定使用统一默认值加项目覆盖，由 CLI 与图形端读写同一套产品配置。CLI 独立提供产品账号新增/登录、MCP 与已选工具的必要设置入口，认证需要时可打开服务商网页，但不依赖 Only my pi 图形端。

相较于两端分别配置或强制在 GUI 设置，这一选择避免接续会话时工具、模型绑定和项目设置出现两套含义，也增加了 CLI 设置交互、跨进程配置冲突和兼容验收的工作。它更新 [2026-09-26 Q17](../plans/2026-09-26-webui-optimization-discussion.md) 中 GUI 专属产品配置的范围，并补充 [ADR-0020](ADR-0020-pi-native-clients-and-shared-sessions.md) 的双正式客户端决定。

以下原约定继续有效：

- 原 Pi、原 CLI 默认配置和用户外部配置保留原归属，仅显式导入；导入不改写来源，也不自动启动工具、登录或授予调用权限。产品账号保持独立身份，不按 Provider 合并凭据。
- 项目覆盖只影响该项目；重置覆盖后继承产品默认值。修改用于后续执行，活动任务继续使用已固定配置；排队项遇配置版本变化暂停核对，加载失败保留最后有效配置并显示原因。
- 必需权限/协调组件不能关闭；无声明 Schema 的资源不提供任意字段编辑。撤权、停用和凭据失效仍按原合同阻止后续调用，不因“下次任务生效”而延后。

当前仅确认配置归属及产品行为，没有选定新存储技术，也没有迁移用户配置。旧 GUI 隔离探针保留原候选与范围，不能用来证明新增双端共享已通过；后续实际 CLI/Pi/图形入口和安装态验收按[开发蓝图](../plans/2026-10-17-product-direction-and-iteration-plan.md)补齐。
