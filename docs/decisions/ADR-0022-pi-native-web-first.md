# ADR-0022 · 原生 Pi 基础先行，WebUI 先于 Electron

Only my pi 的目标是个人桌面 Agent 客户端。先让用户在本机 WebUI 完成一次编程会话，再按需加入模块。待核心体验经持续使用验证、迭代节奏适合打包时，由 Electron 承载同一套 WebUI 和宿主。这样可以在做安装、更新和窗口生命周期之前，先验证用户能否可靠地完成工作。

Pi 负责模型、Agent 循环、工具、上下文和原生会话历史。产品通过 Pi 的公开接口提供项目导航、配对、执行协调、审批和错误恢复。普通会话只装配基础能力。历史由 Pi 保存，产品索引用于查找与展示。

CLI 继续维护，工程上建议与 WebUI 分别迭代。最终两端应当能在匹配的版本、项目和账号下查看历史，并在原执行者完全停止后显式接续。同一会话同一时刻只有一个执行者，旧授权和结果未知的操作不随接续恢复。

本决定更新了 [ADR-0014](ADR-0014-webui-to-electron.md) 和 [ADR-0020](ADR-0020-pi-native-clients-and-shared-sessions.md) 的首版范围与阶段门槛。原有账号、数据、写入所有权和 [ADR-0021 的配置归属](ADR-0021-shared-product-configuration.md) 继续适用。旧规格中的材料、编排和双端能力对等保留为需求来源，按用户选择逐项实施。取舍是首版功能较少，可以更早验证完整的会话旅程。[当前范围与阶段](../plans/2026-10-25-pi-native-client-reset.md)
