# only-my-pi 0.3.0-preview.1

This Preview provides a guarded terminal coding Agent for macOS 14 or newer
on Apple Silicon, with embedded Node 24.19.0, controlled Pi 0.84.3 and the
audited nine-package extension stack.

Run `omp` in a project to enter the Pi TUI directly. The Agent starts in
Inspect, offers interactive model selection, and requests one process-scoped
coding approval before project changes. Complex tasks present a plan first.
Headless operation remains read-only.

Managed-clone writing preserves pre-existing changes and requires runtime
verification and fresh review before integration. Child budgets accumulate
across delegated work, and exhausted budgets prevent further child tools and
writer integration. Public Web access requires separate approval.

Thin retrieves the exact manifest-bound public artifacts before installation.
Full contains the same canonical stack for offline installation. Both payloads
support explicit update, rollback and removal; third-party packages remain
user-owned external bindings.

Preview boundaries:

- macOS Apple Silicon only;
- coding approval applies to the active project and interactive process;
- no automatic project-external writes, destructive Git, deployment or publication;
- no npm publication, MCP, silent YOLO or background updater.

Verify `SHA256SUMS`, the SPDX SBOM and GitHub artifact attestations before
installation. See the repository Quickstart for installation, rollback and
stack-removal instructions.
