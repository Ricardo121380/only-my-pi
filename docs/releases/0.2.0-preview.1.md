# only-my-pi 0.2.0-preview.1

This is the first public Preview of only-my-pi for macOS 14 or newer on Apple
Silicon. It installs a user-local, read-only Pi Agent Harness with embedded Node
24.19.0, Pi 0.84.3 and the exact audited nine-package extension stack.

The Thin payload is the default connected installer. The Full payload contains
the same canonical stack for offline installation and audit. Both payloads are
bound to one stack manifest and must produce the same installed tree identity.

Preview limitations:

- macOS Apple Silicon only;
- Agent execution remains read-only;
- no npm publication, writer, MCP or background updater;
- public Web is per-run confirmed with browser cookies disabled;
- third-party packages remain user-owned external bindings.

Verify `SHA256SUMS`, the SPDX SBOM and GitHub artifact attestations before
installation. See the repository Quickstart for the checksum-first installer,
rollback and complete stack-removal boundaries.
