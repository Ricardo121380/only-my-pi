## 本轮改变

- 将当前开发依赖和实际源运行夹具升级至 Pi 1.5.0。公开会话、输入和 RPC 接口仍复用原生 Pi。保存的 Project Trust 拒绝结果优先于默认信任；没有放宽审批。
- 真实 WebUI 开发入口只列出并接受 DeepSeek 模型。连接测试、任务入口、RPC 执行与子代理分别校验实际模型 ID；账号或模型显示名称不构成证明。本地确定模型服务仅用于协议和失败注入，不是外部模型调用。
- B2 按需通过既有 typed facade 和 delegation-v1 backend 调用 `pi-subagents`，它仍是物理子进程的唯一 owner。只开放 `omp-explorer`，继承所选产品账号、模型及推理强度，fresh context；工具仅 read/grep/find/ls 和内部 structured_output。没有 shell、写入、写入子代理或子代理再次委派。
- 每次主执行最多 4 个子代理、并发 2 个、深度 1。每个子代理有 120 秒和 8 轮限制；当前不宣称已具备累计 Token、费用、所有工具调用或返回字节的硬预算。assignment 中的 maxOutputBytes=65536 只是现有预算元数据，这条 backend 尚未传递或校验它，不计为已落实的上限。无法证明终结时显示未知、请求取消并阻止新的委派，不自动重放。
- 子执行器校验精确的源 Pi SDK 与父 Node 身份。PATH 使用实际 `process.execPath` 的目录，避免源运行时不存在的 `runtime/node/bin` 导致退回其他 Node；账号凭据不进入参数或公开错误。
- 停止期间只保留只读控制状态查询，终态保存实际子代理状态；父任务结束后不会继续把旧子状态显示为运行中。没有重新授予编程权限。
- 新鲜 smoke 回执使用 format 3/Pi 1.5.0；历史 format 1/0.84.1、format 2/1.3.0 仍可校验。门禁内与顶层 smoke 身份副本必须一致。
- 两个新 Host 测试归入 Web CI，每个 Node 测试文件仍只分配一次。共享 SDK/锁修改继续触发所需 CLI 和打包回归，没有另加重复的全量测试。
