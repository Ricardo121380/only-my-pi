# Triage Labels

工程 Skills 使用以下五个角色；本项目直接使用同名 GitHub 标签。

| Label in mattpocock/skills | Label in our tracker | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不予实施 |

Skill 提及某个 triage 角色时，使用本表右列的标签。标签表示任务分流状态，实际执行仍遵守任务范围和授权。

本文件记录名称映射；远程缺少标签时，按当前获准的 tracker 操作创建。标签词汇调整只修改本表并同步有关远程标签，保留其他用途的标签。
